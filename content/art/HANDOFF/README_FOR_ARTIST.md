# Bhagavatam chapter paintings: how to work

Thank you for helping. You will make one painting for each chapter of a devotional reading app (340 chapters; chapter 0.1 is already done and is your style guide).

## What is in this folder
| File | What it is |
|---|---|
| `ch_0_1_REFERENCE.png` | The picture we love. Every new picture must look like it painted by the same hand. |
| `prompts_full.txt` | One complete, ready-to-paste prompt per chapter (340). Copy the block under one `=====` heading, attach the reference picture, generate. |
| `tracker.csv` | Tick off `made` and `approved`, write notes. |
| `../paste_list.md` | Shorter version of the same scenes, if you use a ChatGPT Project (see `../PROMPT_GUIDE.md`). |

## Steps for each picture
1. Open `prompts_full.txt`, find the chapter (for example `ch_10_29`).
2. Attach `ch_0_1_REFERENCE.png` and paste the whole block.
3. Look at the result with the checklist below. If it is close, fix it with one short line in the same chat, for example "Same scene. Move the figures into the right half." Do not re-explain.
4. Save the best one as `ch_10_29.png` (exactly this name: `ch_`, skandha number, `_`, chapter number). Put it in the `raw` folder (`content/art/raw`) or in a folder you send back.
5. Mark it in `tracker.csv`.

Start with the twelve best-loved stories (Prahlada 7.8, Gajendra 8.2, Churning 8.7-8.8, Vamana 8.18-8.20, Putana 10.6, Kaliya 10.16, Govardhana 10.25, Rasa 10.29, Sudama 10.80 and so on) to settle the look, then go in order.

## Checklist before saving a picture
- Same soft gouache-on-paper look, warm low light, as the reference. Not glossy, not 3D, not photographic.
- **The left third is calm sky, water or mist.** The app puts the chapter title there.
- No writing of any kind, no signature, no border or frame.
- Hands, faces and the number of limbs look right. Krishna is dark blue with yellow silk and a peacock feather; Vishnu has four arms.
- No blood, no gore, no nudity (violent stories show the moment before or after).
- Faces calm and kind. It is a devotional book.

## Technical
- Landscape, as large as the tool allows (3:2 or 16:10 both fine; the app crops to 16:10).
- PNG or JPG is fine. File name must be exactly the chapter code.
- If a tool refuses a prompt, add "a traditional devotional temple painting" once. If it still refuses, tell us the chapter code and we will change the scene.
- Each prompt also lists the Skandha colour (saffron, indigo, and so on) in its TIME AND LIGHT line. Keep it, it makes each book feel different.

## Not included here
