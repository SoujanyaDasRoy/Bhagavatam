# Filling the missing Bengali and Odia verses

Run these in your own terminal, from the project root. The list of verses is in the README (generated by `python tools/content/missing_report.py`).

The report found no missing verse that sits inside a printed joint group (groups such as 5-8 already point to their first verse), so every row is either an extraction miss or a verse not in the print.

## Bengali (232 verses)
```powershell
cd content\_bengali\bn_extract
# 1. add any joint group or misprint to data\numbering_fixes.json first
# 2. re-read only the pages that hold the verses (page numbers: see content\bn\skandha-NN\chapter-NN.md "source_pages")
python vision_extract.py run --vol 1 --pages <first>-<last> --workers 2
python bn_extract.py assemble
python ..\..\_build\promote_bengali.py --force
python ..\..\_build\add_bengali.py ..\..\content.db
python ..\..\_build\add_bengali.py ..\..\..\app\src\main\assets\content.db
cd ..\..\..
python tools\content\missing_report.py --readme
```

## Odia (122 verses)
```powershell
cd content\_localocr
# re-read the pages of the chapters listed in the README, then assemble and check (see docs\agent for the readers)
python run_settle.py
python ..\_odia\odia_assemble.py
cd ..\..
python content\_build\add_odia.py content\content.db 13
python content\_build\add_odia.py app\src\main\assets\content.db 13
# rebuild search.db with the same content version, then:
python tools\content\missing_report.py --readme
```

After each run: `content/content.db` and `app/src/main/assets/content.db` must be identical, and `search.db` must carry the same `content_version`.
